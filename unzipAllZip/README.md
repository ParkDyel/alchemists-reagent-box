# unzipAllZip

지정한 폴더의 ZIP 파일에서 HEIC 파일만 꺼내는 도구입니다.

## 사용법

Node.js 18 이상에서 의존성을 설치한 뒤 실행합니다.

```powershell
npm ci
npm run extract -- "C:\사진\압축파일"
```

ZIP 내부의 폴더 구조는 유지하지 않고 HEIC 파일을 지정한 폴더에 바로 저장합니다. 같은 이름의 파일이 있으면 덮어씁니다. 확장자 `.heic`와 `.zip`은 대소문자를 구분하지 않습니다.

각 ZIP의 HEIC 파일을 추출하고 출력 파일을 확인한 뒤 해당 ZIP을 삭제합니다. HEIC 파일이 없는 ZIP도 처리 완료로 간주하여 삭제합니다. ZIP 하나가 실패하면 오류를 출력하고 그 ZIP은 남긴 채 다음 ZIP을 처리합니다. 실패 전에 이미 추출한 파일은 그대로 남으며, 하나라도 실패하면 종료 코드가 `1`입니다.
